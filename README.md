# Sawakli-AI

Welcome to the Sawakli-AI project repository.

## Project Structure

- `agent/`: AI Agent service
- `api/`: Backend API service
- `connector/`: External integration connectors
- `database/`: Database configurations and scripts
- `ui/`: User Interface / Frontend application
- `worker/`: Background worker services

## Getting Started

To run the project locally, you can use Docker Compose:

```bash
docker-compose up -d
```
